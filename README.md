# MyMediaStuff

MyMediaStuff is a desktop application for cataloguing and organizing
images and videos while keeping original media files in their existing
locations. The project prioritizes local processing, user privacy and
WebM compatibility, adding the possibility to add more modules to customize
the overall experience.

CURRENT DEVELOPMENT GOALS
-------------------------
- Select folders and discover supported images and videos.
- Display media items in a desktop library interface.
- Read video information and create previews with FFmpeg.

PLANNED FEATURES (NOT YET IMPLEMENTED)
--------------------------------------
- Persistent media catalog and advanced search.
- Manual tags, metadata editing and filename-based tag suggestions.
- Multi-frame video thumbnails and timeline previews.
- Local AI-assisted classification and semantic search.
- Subtitle management and speech-to-text transcription.
- External visual search, enabled explicitly by the user to add losen tags.
- Secure encrypted storage for selected files.

PRIVACY
-------
Local-first by design. Everything is controlled by the user.

STATUS
------
Early development. More features to come. Feel free to message me your ideas.
